# Fighter Strength & Power - Four-Week Base

Status: approved and registered in the local app source; not deployed or assigned.
Program version: 1.0.0. Authoring date: 2026-11-14.
Duration: four weeks from the actual start date, which has not been set.
Priority: relative strength, then explosive power, then repeat-round endurance.
Secondary aim: targeted upper-chest, calf and biceps development.

## The week

| Day | Session |
|---|---|
| Monday | Scheduled MMA striking class; log drills, pads, live rounds and actual duration |
| Tuesday | Strength A, brief power practice, accessories/core and optional easy bike |
| Wednesday | ONE class: grappling or conditioning; record which and how demanding |
| Thursday | Strength B, brief power practice, accessories/core and optional easy bike |
| Friday | Chosen course-led technical bag lesson; usually 6-8 rounds of 2-3 min, 60s rest |
| Saturday | Shorter Strength C plus chosen technical bag lesson |
| Sunday | Day off by default; optional recovery session, logged if performed |

Monday, Wednesday, Friday and Sunday use the existing custom free-text/duration logging.
Saturday has lifting and bag blocks; use session/item notes for course, lesson, actual round
lengths and deviations. Course combinations are not invented here. A 90-minute limit is a
ceiling; there is no need to fill unused time with extra rounds.

## Effort, loading and rest

- RIR means clean repetitions still available. Most listed work targets about 3 RIR.
- Week 1: use the two-set base shown in the cartridge and keep 3-4 RIR.
- Weeks 2-3: use the full doses in the tables below if recovery allows. For marked exercises,
  add a third performed set with the player's Add set control; keep about 3 RIR.
- Main-lift rest is 2-3 minutes where shown. Do not compress rest to make lifting feel like cardio.
- Accessory rest is generally 60-90 seconds. Work through stations in order; no supersets.
- Power sets are fresh, low-repetition practice. Stop before slowing, noisy landings or poor control.
- First squat exposure: 60-65 kg TOTAL only if warm-ups are comfortable; lower it if needed.
- First incline barbell exposure: 40 kg TOTAL only if comfortable; lower it if needed.
- These are conservative starting suggestions, not calculated max percentages or mandatory loads.
- For machines, dumbbells and curls, choose loads for the listed range with the intended reserve.
  Keep machine model/setup consistent; loads from different machines are not interchangeable.

## Tuesday - Strength A

10-min warm-up, about 5 min power, 35 min main strength, 12 min calves/arms, 5 min core,
optional 10 min easy bike, 5 min cooldown and about 5 min transitions: approximately 87 min.
The warm-up allowance includes preparation sets; take those sets immediately before their lift.

| Exercise | Listed work sets x reps | Rest / loading notes |
|---|---|---|
| Countermovement Jump | 3 x 3 | 90s. Reset each rep; stop before speed or landing quality drops. |
| Barbell Back Squat | 3 x 4-6 | 150-180s. First session: try 60-65 kg total only if warm-up sets feel easy; adjust down as needed. |
| Incline Barbell Bench Press | 3 x 6-8 | 120-180s. First session: try 40 kg total if comfortable; no forced repetitions. |
| Plate-Loaded Lat Pulldown | 3 x 6-8 | 120s. |
| Standing Calf Raise Machine | 3 x 10-15 | 60-90s. |
| Standing Dumbbell Curl | 2 x 8-12 | 60-90s. |
| Dead Bug | 2 x 6-8 each side | 45-60s. |

Optional bike: 10 min at full-sentence conversational effort. Skip if class fatigue or time
would compromise the session. Record the omission; do not rush main-lift rest.

The pulldown is the loadable vertical-pull anchor because no secure added-load belt is confirmed.
Saturday retains strict bodyweight pull-ups. Do not hold a loose dumbbell between the feet.

## Friday - Course-led bag practice

Use the chosen Varga or Jeff Chan lesson. Warm up with shadowboxing and footwork for around
10 min. Perform the actual lesson, usually 6-8 x 2-3 min with 60s rest, at controlled technical
intent; finish with around 5 min comfortable cooldown/mobility. Do not add hard intervals merely
to reach 90 min. Core is optional only if fresh and time permits; it is already programmed twice.

Log provider, lesson/combination names, actual rounds, round length/rest and an honest session
difficulty note. No proprietary lesson is reproduced or replaced by invented combinations.

## Saturday - Strength C and technical bag

10-min warm-up, about 40 min lifting, 17 min bag for 6 x 2 min with 60s between rounds,
about 7 min transitions and 5 min cooldown: approximately 79 min.
Six 3-min rounds make approximately 85 min; eight 2-min rounds make approximately 85 min.
Choose ONE option, not both. Keep the full session within 90 min.

|---|---|---|
| Leg Press Machine | 2 x 8-10 | 90s. |
| Incline Dumbbell Bench Press | 2 x 8-12 | 90s. |
| Strict Bodyweight Pull-Up | 2 x 8-12 | 90-120s. |
| Shoulder Press Machine | 2 x 8-10 | 90s. |
| Leg Curl Machine | 2 x 10-15 | 60-90s. |

Power is not added here: Tuesday and Thursday already provide fresh power practice. Saturday
is intentionally moderate. Bag practice follows the chosen course and stays technical after
lifting. Stop the bag block if fatigue degrades stance, coordination or control.

## Progression through the month

| Week | Instructions |
|---|---|
| 1 | Establish repeatable technique and loads; use the two-set base; 3-4 RIR |
| 2 | Add marked third sets only if classes and general recovery remain comfortable |
| 3 | Add reps within the range, then the smallest available load after all sets reach the top cleanly |
| 4 | Keep week-3 dose if recovering well; otherwise return to the two-set base, use easy loads and omit optional conditioning; review at the end |

For a main lift, increase by the smallest available plate increment on its next exposure after
all work sets reach the top of the range at the intended reserve. Return toward the lower rep
bound after adding load. Use the same rule for dumbbells/machines, accepting that large stack
jumps may mean keeping the same load longer. Never increase load, set count and cardio intensity
all at once just to make the session harder.

Bodyweight pull-ups are quality practice with at least three reps left, not a maximal strength
test. Once 2 x 12 is consistently comfortable, retain that dose for this block and review secure
weighted-pull-up options later; no purchase is required now. Jump/slam progression is better
repeatability and speed with the same low dose, not extra fatigue or automatic load increases.

Do not turn technical bag rounds into hard intervals as a progression rule. Classes already
count toward conditioning. Sunday stays optional. No max testing, peak-fight week, weight cut
or automatic phase change is prescribed.

## Weekly dose and rationale

At the listed week-2/3 dose:
- Chest: 7 direct sets (3 Tuesday incline, 2 Thursday press, 2 Saturday incline).
- Calves: 7 direct sets (5 standing, 2 seated).
- Biceps: 4 direct sets plus pulling work.
- Main vertical/horizontal pulling: 8 sets plus 2 rear-delt sets; pressing: 9 sets.
- Lower body: squat, split squat, leg press, hip extension and knee flexion.
- Core: 4 anti-extension/anti-rotation sets.
- Power: 9 jumps and 9 slams across two sessions.
- Supplemental easy bike: up to 20 min; classes and bag practice provide other training exposure.

These starting doses are coaching choices, not universal growth minima or guaranteed visible
changes in one month. Incline pressing prioritizes an upper-chest stimulus; standing and seated
calf work cover different knee positions; curls provide direct arm work.
A conventional loaded hip hinge is deliberately absent to honor the earlier no-deadlift
preference. Glute-machine hip extension and leg curls train relevant musculature but do not
teach or fully substitute the hinge skill; reconsider at review if preferences change.
There is no claim that easy bike alone establishes fight readiness or a particular aerobic gain.

## Review after four weeks

Compare consistent loads/reps and technique on squat, incline and pulling; strict pull-up
quality; class/bag execution; session difficulty and recovery; completed sessions; and tolerance
of extra chest/calf/biceps work. Optional circumference/photos can track appearance, but one
month is a short observation window. Do not chase a max test to prove progress.
If adherence and recovery are good, the next block can add targeted volume or conditioning
based on the weakest demonstrated quality. Otherwise repeat or reduce this block.

duration are read-only guidance: log actual work through activity selections and item/session
notes; there is no per-round counter. The app does not automatically change set counts or
switch phases after four weeks. Choose the matching
weekday template manually; a skipped day is not training debt. Classes require no exact duration
assumption. Recovery sessions do not replace the rest default.
